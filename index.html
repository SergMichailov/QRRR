A quick field guide

From screen to successful scan

A QR code is only useful when people can scan it and trust where it leads. These checks help avoid common problems before you print or publish one.

01 / DESTINATION

Use a short, stable link

Long URLs create denser patterns that can be harder to scan. Use a destination you control, check it on a phone, and avoid links that expire or require unexpected sign-in.

02 / CONTRAST

Keep dark modules on light

Scanners need a clear difference between the code and its background. Avoid pale foreground colors, gradients, transparent backgrounds, and placing a code over a photograph.

03 / OUTPUT

Test the final size

Scan the actual printed proof or on-screen design with more than one phone. Keep a clear border around the code and do not stretch, crop, or cover its corners.

Choosing error correction

Error correction lets a QR code remain readable when some of its data is obscured or damaged. Higher levels add more redundant data, which can make the pattern denser. That extra tolerance is useful for labels that may get scratched, but it does not make an unreadable design reliably scannable.

For a clean digital display, Low or Medium is often enough. For a printed item handled frequently, Quartile or High can offer more resilience. If you use a logo or decorative treatment, keep it small and test the finished code; the simplest, highest-contrast design is usually the most dependable.

Image dimensions are not a substitute for print resolution. When preparing a printed piece, place the downloaded PNG at an appropriate physical size, preserve its square proportions, and scan a real proof at the distance people will use it.

Common questions

Before you publish

Does this generator upload my text?

The QR image is generated in your browser using a JavaScript library loaded by this page. The entered text is not sent to a QR-generation service by this tool. The destination you encode may still be visible to anyone who scans the code, so do not include private information.

Why does my code fail to scan?

Common causes include weak color contrast, a very long destination, a code printed too small, a missing clear border, or a damaged image. Try a dark foreground on white, a shorter link, and a fresh download; then scan the actual final design.

Can I use a QR code for a permanent destination?

The encoded value does not change after download. If the destination URL changes, the QR image will still point to the old address. Use a short link on a domain you control when you need to update the destination later.

Which file should I download?

This tool downloads a PNG, which is convenient for websites and many common layouts. For a large print job, check the resolution at the intended physical size and request a vector format from a suitable design tool if the printer requires one.
